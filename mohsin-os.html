Mohsin OS

An agentic operating system I designed and built to automate real commerce, job-search and business workflows. The goal is not another dashboard: it is a system that discovers work, executes repeatable steps, preserves evidence and brings only consequential decisions back to the human operator.

Open Live Showcase → View Portfolio
The problem

Too much work was being repeated manually.

Product research, supplier checks, listing preparation, job discovery, application tracking and portfolio documentation were all separate workflows. Mohsin OS was created as one operating layer that can connect those workflows and turn them into repeatable agent tasks.

Current proof
Live

Public production showcase, deployed API, persistent database/auth foundation, protected operator routes and active Commerce + Jobs modules.

What I solved in production

The work included the failures.

Building the system meant debugging monorepo builds, deployment drift between frontend and backend, Supabase SSR/PKCE recovery behavior, environment variables, protected internal API calls, persistent workspace data, OAuth boundaries and free-tier cold starts. Those production failures became part of the engineering evidence, not something hidden from the story.

Safety boundary

Human approval is mandatory.

Agents may research and prepare work, but Mohsin OS does not automatically publish commerce listings. External publishing remains an explicit operator decision.

Constraint engineering

Built under a bootstrap budget.

The first production version intentionally uses free-tier infrastructure and on-demand execution so revenue can fund the next infrastructure step instead of paying for hypothetical scale.

What comes next

Use it first. Measure it. Then scale it.

The immediate objective is to use Mohsin OS personally: generate real commerce evidence, improve the Jobs Engine, document measurable outcomes, and turn those outcomes into a feedback loop. Only after the workflows prove useful will the platform expand toward broader multi-user access.
